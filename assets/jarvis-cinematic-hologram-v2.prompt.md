# 全息战甲启动素材 v2

- 项目素材：`assets/jarvis-cinematic-hologram-v2.png`，1024×1536 RGBA，四角透明；原文件保持不变。
- 制作方式：内置 image_gen 工具，`transparent_background=true`。未使用独立 OpenAI API、未读取任何本机密钥。
- 造型：原创未来装甲人形；工作台式冷青全息、透明内构与少量暖色机械关节。不是电影截帧，也不是原电影 3D 模型。
- 运行时：本地 C# 投影渲染，按光点扫描汇聚，加入细微视差、局部眼部像素闪烁及胸口脉冲。素材缺失时回退程序化曲面点云。
- 视觉参考：[工作台全息投影画面](https://www.imore.com/apple-smart-homes-and-future)，仅用于观察层次与光效，没有把该电影图片打包进应用。
- 当前素材、制作说明及程序渲染预览已纳入仓库发布清单；参考电影图片不随项目分发。
